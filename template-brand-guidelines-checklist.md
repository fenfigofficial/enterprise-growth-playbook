# Brand guidelines checklist

- [ ] Purpose and positioning statement
- [ ] Logo versions, clear space, minimum size
- [ ] Colour palette with exact codes
- [ ] Typography: headings, body, usage rules
- [ ] Imagery and icon style
- [ ] Voice and tone with do and do-not examples
- [ ] Templates: presentation, document, social, email
- [ ] Asset library with one owner
- [ ] Approval routine for new material

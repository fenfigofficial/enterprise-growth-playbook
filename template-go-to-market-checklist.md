# Go-to-market checklist

- [ ] Ideal customer profile written and agreed
- [ ] Problem statement and offer in one sentence
- [ ] Pricing and packaging defined
- [ ] Proof ready: case study, reference or pilot result
- [ ] Two or three channels chosen with an owner each
- [ ] Content calendar for the first 90 days
- [ ] Sales stages, entry and exit rules defined
- [ ] Response-time standard for new enquiries
- [ ] Tracking in place: leads, conversion, cycle length, deal size
- [ ] Weekly review of pipeline and results
